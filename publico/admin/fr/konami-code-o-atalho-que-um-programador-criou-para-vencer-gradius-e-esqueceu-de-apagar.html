Konami Code : le raccourci qu'un programmeur a créé pour battre Gradius et oublié de supprimer

Haut, haut, bas, bas, gauche, droite, gauche, droite, B, A est né comme test interne en 1986 et est devenu le code le plus célèbre du jeu vidéo.

Par Équipe Aloha10 novembre 2026, 10:44

PartagerWhatsAppXFacebookTelegram

Haut, haut, bas, bas, gauche, droite, gauche, droite, B, A. Même ceux qui n'ont jamais joué à l'ère des 8 bits reconnaissent cette séquence. Elle a un auteur, une date et une motivation peu héroïque : le programmeur n'arrivait pas à finir le jeu qu'il adaptait. Pour raconter l'histoire, j'ai lu l'interview de 2003 du créateur, traduite et citée par Engadget, et les pages de Wikipédia sur le code et sur le programmeur. Les deux pages se contredisent sur un point, que je montre plus bas.

Un jeu trop difficile

L'auteur est Kazuhisa Hashimoto, de Konami (Engadget écrit son prénom Katsuhisa). En 1986, il travaillait sur la version NES de Gradius, un jeu de vaisseau né en arcade en 1985. Selon Engadget, l'équipe comptait quatre personnes. Hashimoto a raconté qu'un subordonné avait fini la version arcade et trouvé le jeu très difficile. Lui-même, dit-il, avait peu joué et n'arrivait pas à le battre, alors il a mis le code. Et, selon ses mots, il s'est assuré qu'il soit « facile à retenir ».

Ce que faisait le code

Dans Gradius, la séquence donne tous les bonus d'un coup, jeu en pause, d'après Wikipédia. C'était un outil de test : un programmeur doit pouvoir atteindre les derniers niveaux sans tout rejouer à chaque modification. Wikipédia le décrit comme une fonction de test interne, et Hashimoto a lui-même choisi une séquence facile à retenir.

L'oubli

Le plan était de retirer le code avant la sortie. Ce n'est pas ce qui s'est passé. Ici, les deux pages de Wikipédia divergent. Celle sur le code affirme qu'il a été découvert quand le jeu était préparé pour la production de masse et que l'équipe a décidé de le garder, car le retirer risquait de provoquer des bogues (ce passage est signalé « référence nécessaire »). Celle sur Hashimoto dit que le jeu est sorti avec le code et que ce sont les joueurs qui l'ont trouvé et ont prévenu Konami. Engadget n'aborde pas ce point. Ce que les trois versions ont en commun, c'est le résultat : la séquence est restée.

Comment elle est devenue légende

La renommée internationale est venue avec Contra, sur NES. Wikipédia dit que le code s'est popularisé chez les joueurs nord-américains grâce à cette version, où il donne 30 vies, ce qui explique des surnoms comme « Contra Code » et « 30 Lives Code ». En japonais, le nom est Konami Command. L'entreprise a réutilisé la séquence dans d'autres jeux de la série Gradius et d'autres licences, avec des variations. Sur Wikipédia figurent des exemples comme Gradius Galaxies, sur Game Boy Advance, où le vaisseau s'autodétruit après les bonus (passer à gauche, gauche, droite, droite évite la pénalité), et Tetris Effect, où le nombre 06061984 débloque un niveau.

Hors des jeux

Le code a aussi échappé aux jeux. La liste de Wikipédia inclut des assistants vocaux qui répondent à la séquence par des blagues, comme Siri (« Cheater! ») et Google Assistant (« Cheat mode enabled »), et un site ou deux avec des fonctions cachées, comme Discord, qui débloque un jeu de serpent sur une page d'erreur 404. La page elle-même prévient que certaines de ces entrées manquent encore de meilleures sources ; mieux vaut donc les prendre comme des curiosités, pas comme une garantie qu'elles fonctionnent aujourd'hui. Il existe même une chanson, « Anyone Else but You », des Moldy Peaches, de 2001, qui cite la séquence.

L'homme derrière

Hashimoto est entré chez Konami en 1981, en commençant par des cartes électroniques pour machines à jetons, et a travaillé sur au moins neuf jeux, dont The Goonies et International Superstar Soccer, selon Wikipédia. Il est né le 15 novembre 1958 et mort le 25 février 2020, à 61 ans, ce que Konami a confirmé. Les pages que j'ai lues n'en donnent pas la cause. Un détail curieux de Wikipédia : la page le décrit comme quelqu'un qui a créé le code « sans le vouloir », ce qui colle avec l'histoire de l'oubli.

Sources : Engadget (en anglais), Wikipédia : Konami Code (en anglais) et Wikipédia : Kazuhisa Hashimoto (en anglais).
