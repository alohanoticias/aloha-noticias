コナミコマンド：プログラマーが『グラディウス』をクリアするために作り、消し忘れた近道

上上下下左右左右BAは1986年に社内テストとして生まれ、ビデオゲームで最も有名なコマンドになりました。

執筆： アロハ編集部2026年11月10日, 10:44

シェアWhatsAppXFacebookTelegram

上、上、下、下、左、右、左、右、B、A。8ビット時代に遊んだことがない人でも、この並びは知っています。これには作者と日付があり、英雄的とは言いがたい動機がありました。移植していたゲームを、プログラマー自身がクリアできなかったのです。この話を書くために、Engadgetが翻訳・引用している作者の2003年のインタビューと、コマンドおよびプログラマーに関するWikipediaの2ページを読みました。2つのページは1点で食い違っており、それは後ほど示します。

難しすぎたゲーム

作者はコナミの橋本和久氏（Kazuhisa Hashimoto）です（Engadgetは名をKatsuhisaと綴っています）。1986年、彼は1985年にアーケードで生まれたシューティング『グラディウス』のファミコン版に取り組んでいました。Engadgetによれば、チームは4人でした。橋本氏は、部下がアーケード版を最後まで遊び、とても難しいゲームだと感じたと語っています。自分自身はあまり遊んでおらず、クリアできなかったので、コマンドを入れたといいます。そして彼の言葉では、「覚えやすい」ものにしておいたそうです。

コマンドの働き

Wikipediaによれば、『グラディウス』ではこの入力で、ポーズ中にすべてのパワーアップが一度に手に入ります。テスト用のツールでした。プログラマーは、修正のたびに最初から遊び直さなくても終盤のステージに到達できる必要があります。Wikipediaは社内テスト用の機能と説明しており、橋本氏自身が覚えやすい並びを選びました。

消し忘れ

予定では、発売前にコマンドを消すはずでした。そうはなりませんでした。ここで2つのWikipediaのページは食い違います。コマンドのページは、ゲームが量産の準備をしているときに発見され、削除するとバグを起こしかねないため残すことにした、と述べています（この部分には「要出典」の印があります）。橋本氏のページは、ゲームがコマンド入りのまま発売され、プレイヤーが見つけてコナミに知らせた、としています。Engadgetはこの点に触れていません。3つに共通するのは結果です。並びは残りました。

伝説になるまで

国際的な名声は、ファミコン版『魂斗羅』とともに来ました。Wikipediaは、このバージョンで30機になることから北米のプレイヤーに広まったと述べ、「Contra Code」「30 Lives Code」という呼び名の理由だとしています。日本語での名前はコナミコマンドです。会社はこの並びを、グラディウスシリーズの他作品や別のシリーズにも、変化をつけて再利用しました。Wikipediaには、ゲームボーイアドバンス版『Gradius Galaxies』でパワーアップ後に自機が自爆する例（左、左、右、右に変えると罰を避けられる）や、『Tetris Effect』で数字06061984によりステージが解放される例が載っています。

ゲームの外へ

このコマンドはゲームの外にも飛び出しました。Wikipediaの一覧には、この並びに冗談で返す音声アシスタント、たとえばSiri（「Cheater!」）やGoogleアシスタント（「Cheat mode enabled」）、そして隠し機能のあるサイト、たとえば404エラーページでスネークゲームが出るDiscordなどが挙がっています。ページ自体が、これらの項目の一部にはより良い出典が必要だと注意しているので、今も動く保証ではなく雑学として扱ってください。2001年のThe Moldy Peachesの曲「Anyone Else but You」がこの並びに触れているほどです。

背後にいた人

Wikipediaによれば、橋本氏は1981年にコナミに入社し、メダルゲーム機の基板から始め、『グーニーズ』や『International Superstar Soccer』を含む少なくとも9本のゲームに携わりました。1958年11月15日に生まれ、2020年2月25日に61歳で亡くなり、コナミがそれを確認しました。私が読んだページに死因は書かれていません。Wikipediaの興味深い細部として、同ページは彼を「うっかり」コマンドを作った人物として描いており、消し忘れの話と合っています。

出典：Engadget（英語）、Wikipedia: Konami Code（英語）、Wikipedia: Kazuhisa Hashimoto（英語）。
