Konami Code: the shortcut a programmer made to beat Gradius and forgot to delete

Up, up, down, down, left, right, left, right, B, A began as an internal test in 1986 and became the most famous code in video games.

By Aloha TeamNovember 10, 2026, 10:44

ShareWhatsAppXFacebookTelegram

Up, up, down, down, left, right, left, right, B, A. Even people who never played in the 8-bit era recognize this sequence. It has an author, a date and a very unheroic motivation: the programmer couldn't beat the game he was adapting. To tell the story I read the creator's 2003 interview as translated and cited by Engadget, and the Wikipedia pages on the code and on the programmer. The two pages contradict each other on one point, which I show below.

A game too hard

The author is Kazuhisa Hashimoto, of Konami (Engadget spells his first name Katsuhisa). In 1986 he was working on the NES version of Gradius, a spaceship shooter that was born in arcades in 1985. According to Engadget, the team had four people. Hashimoto said a subordinate played the arcade version to the end and found the game very hard. He himself, he said, had played little and couldn't beat it, so he put in the code. And, in his words, he made sure it was “easy to remember”.

What the code did

In Gradius, the sequence gives all the power-ups at once, with the game paused, according to Wikipedia. It was a testing tool: programmers need to reach the final stages without replaying everything after each tweak. Wikipedia describes it as a feature for in-house testing, and Hashimoto himself chose a sequence that was easy to remember.

The oversight

The plan was to remove the code before release. That's not what happened. Here the two Wikipedia pages diverge. The one on the code says it was discovered when the game was being prepared for mass production and that the team decided to keep it, since removing it could cause bugs (that passage is marked “citation needed”). The one on Hashimoto says the game shipped with the code and that players found it and told Konami. Engadget doesn't address this point. What the three versions have in common is the result: the sequence stayed.

How it became legend

International fame came with Contra, on the NES. Wikipedia says the code became popular among North American players because of that version, in which it gives 30 lives, which explains nicknames like “Contra Code” and “30 Lives Code”. In Japanese, the name is Konami Command. The company reused the sequence in other games of the Gradius series and in other franchises, with variations. On Wikipedia there are examples such as Gradius Galaxies, on the Game Boy Advance, where the ship self-destructs after the power-ups (switching to left, left, right, right avoids the penalty), and Tetris Effect, where the number 06061984 unlocks a stage.

Beyond games

The code also escaped the games. Wikipedia's list includes voice assistants that answer the sequence with jokes, such as Siri (“Cheater!”) and Google Assistant (“Cheat mode enabled”), and a website or two with hidden features, such as Discord, which unlocks a Snake game on a 404 error page. The page itself warns that some of these entries still need better sourcing, so treat them as trivia and not as a guarantee they work today. There is even a song, “Anyone Else but You” by The Moldy Peaches, from 2001, that cites the sequence.

The man behind it

Hashimoto joined Konami in 1981, starting with circuit boards for medal-game machines, and worked on at least nine games, among them The Goonies and International Superstar Soccer, according to Wikipedia. He was born on November 15, 1958 and died on February 25, 2020, aged 61, which Konami confirmed. The pages I read don't give the cause. A curious detail from Wikipedia: the page describes him as someone who created the code “inadvertently”, which fits the oversight story.

Sources: Engadget, Wikipedia: Konami Code and Wikipedia: Kazuhisa Hashimoto.
